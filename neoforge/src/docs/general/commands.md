# Keybinds & Commands

## Keybinds

- `K`: open global combat settings (client-side keybind).

## Server commands (OP-only)

- `vo_takeheld [radius]`: takes the nearest villager’s held items (main/offhand) and puts them into your inventory.
- `vo_fixgenprices [radius]`: recalculates villager offer pricing based on Generosity-only (resets other discount sources).

## Client commands (debug/dev)

This mod includes a few client-side dev commands (for example model/part visibility debugging).
